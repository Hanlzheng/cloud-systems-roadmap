# Reading list

One paper a week, in order. The first two are the friendliest — read them first to get a feel for what a systems paper is like. After each one, write a page in `notes/papers/`: what problem it solves, the core idea, what you didn't understand.

## Starter (during Phases 1–2)

- [ ] MapReduce: Simplified Data Processing on Large Clusters (OSDI 2004)
- [ ] The Google File System (SOSP 2003)
- [ ] Dynamo: Amazon's Highly Available Key-value Store (SOSP 2007)
- [ ] In Search of an Understandable Consensus Algorithm (Raft) (USENIX ATC 2014)

## Intermediate (during Phase 3)

- [ ] Large-scale cluster management at Google with Borg (EuroSys 2015)
- [ ] Spanner: Google's Globally-Distributed Database (OSDI 2012)
- [ ] Firecracker: Lightweight Virtualization for Serverless Applications (NSDI 2020)
- [ ] Dapper, a Large-Scale Distributed Systems Tracing Infrastructure (Google 2010)

## By direction (Phase 4, pick what fits)

- Databases: Architecture of a Database System (Hellerstein et al.); the CMU 15-445 reading list
- ML systems: Megatron-LM; vLLM (Efficient Memory Management for LLM Serving with PagedAttention)
- Serverless: Cloud Programming Simplified: A Berkeley View on Serverless Computing
- Security: gVisor architecture docs; Intel SGX Explained

## Blogs (anytime)

- AWS Architecture Blog
- Google SRE Book (free online; read the first 10 chapters)
- Cloudflare Blog (engineering posts)
- The Morning Paper (archived, great paper walkthroughs)
- Jepsen reports (how real databases behave under failure — reads like detective fiction)
